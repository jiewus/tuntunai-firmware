# 编译和烧录

项目已使用 ESP-IDF 5.5.4 验证。每次打开新终端后先进入固件目录并加载
ESP-IDF 环境：

```bash
cd ESP32-C5.Firmware
source "$HOME/.espressif/v5.5.4/esp-idf/export.sh"
```

列出可用板型并构建：

```bash
python scripts/build.py --list-boards
python scripts/build.py movecall-moji2-esp32c5 build
```

板型的目标芯片、组件依赖和 sdkconfig 默认值由
`main/boards/<board>/` 提供，不要执行 `idf.py set-target`。开发构建输出到
`build/<board>/debug`，不同芯片使用互相隔离的配置和产物。

常用维护命令：

```bash
python scripts/build.py movecall-moji2-esp32c5 reconfigure
python scripts/build.py movecall-moji2-esp32c5 menuconfig
python scripts/build.py movecall-moji2-esp32c5 fullclean
```

烧录并查看日志：

```bash
python scripts/build.py movecall-moji2-esp32c5 flash-monitor \
  -p /dev/cu.usbmodemXXXX
```

退出日志监视器按 `Ctrl+]`。发布构建使用 `python scripts/release.py <board>`，
其安全启动、Flash 加密和签名密钥要求见项目 README。

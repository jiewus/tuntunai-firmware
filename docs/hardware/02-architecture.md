# ESP32-C5 语音助手 - 架构候选

- 日期：2026-07-11
- 阶段：2 - 架构候选
- 前提：ESP32-C5、ES8311、ST77916 已指定，因此不替换主控做国产/海外 MCU 对比；候选方案改为比较语音处理边界。
- 已确认硬件：ESP32-C5 N16R8、ST77916 QSPI 360x360 插接屏、4 ohm 3 W 扬声器、无电池。
- 项目边界：个人娱乐，不量产，不进行产品认证。
- 架构决策：用户已确认采用方案 A 云端半双工；方案 B/C 不进入首版设计范围。

## 架构对比

| 方案 | 架构 | 关键模块范围 | 开发周期 | 功耗/BOM | 软件复杂度 | 主要优点 | 主要风险 | 结论 |
|---|---|---|---|---|---|---|---|---|
| A 云端半双工 | C5 本地唤醒、Opus、UI；云端 ASR/LLM/TTS | C5 + ES8311 + 功放 + ST77916 + Wi-Fi | 最短 | 最低 | 中 | 与 C5 算力匹配，容易形成完整体验 | 依赖网络；单麦远场和回声抑制有限 | 已选择 |
| B 混合语音前端 | C5 负责联网/UI，独立 AFE/DSP 负责多麦、VAD、AEC、唤醒 | A 方案外加双麦 AFE/DSP | 中 | 中高 | 高 | 远场和打断体验更稳定 | 增加器件、固件协议和调音工作 | 体验升级备选 |
| C 本地智能伴随处理器 | C5 负责控制/UI，Linux/AI SoC 负责离线 ASR/LLM/TTS | C5 + AI SoC/模组 + DDR/eMMC + 音频前端 | 最长 | 最高 | 很高 | 可减少云依赖，具备离线能力 | C5 不再是核心算力，热设计和成本显著增加 | 不建议首版 |

## 推荐架构

半双工状态约束：待命时开启本地唤醒；进入录音后停止本地唤醒并上传用户音频；进入播放后停止录音上传；播放结束后重新进入待命监听。

```text
USB-C 5V/2A
   |
   +--> 3.3V DCDC --> ESP32-C5 N16R8 --> Wi-Fi --> 云端 ASR --> LLM --> TTS
   |                       |   |
   |                       |   +--> QSPI --> ST77916 LCD
   |                       |
   |                       +--> I2C 配置 --> ES8311
   |                       +--> I2S 音频 <--> ES8311 <--> 模拟麦克风
   |
   +--> 5V/功放电源 --> Class-D PA --> 4 ohm 扬声器
   +--> 背光电源/驱动 --> LCD 背光

USB/JTAG/UART --> 下载、日志、产测
按键/LED       --> 配网、静音、强制对话和状态提示
```

## 固件分层

| 层级 | 职责 |
|---|---|
| BSP | C5 时钟/GPIO、I2C、I2S、QSPI LCD、背光、按键、功放使能 |
| 音频服务 | 16 kHz 单声道采集、WakeNet9s、Opus 编解码、播放队列、提示音 |
| UI 服务 | LVGL、状态栏、表情、字幕、配网和升级界面 |
| 网络服务 | Wi-Fi 配网、TLS、WebSocket/MQTT、断线重连、时间同步 |
| 会话状态机 | 待命、唤醒、聆听、思考、播放、错误、升级 |
| 云端 | 设备鉴权、流式 ASR、LLM、流式 TTS、会话和 OTA 元数据 |

## 第一版必须准备

1. 启用并验证 ESP32-C5 N16R8 的 8 MB PSRAM，完成全部 GPIO 复用表。
2. 获取 ES8311 和 LCD 模组的原理图、连接器引脚表、时序、初始化表、3V供电范围和背光电气参数。
3. 增加外置 Class-D 功放、麦克风偏置与模拟滤波、电源和 ESD 保护。
4. 准备云端 ASR、LLM、TTS 服务及设备鉴权接口，优先支持流式协议。
5. 建立 ESP-IDF 工程，先分别打通 LCD、录音、播放、Wi-Fi，再集成状态机。
6. 准备示波器、逻辑分析仪、USB 电流表和基础音频测试素材。

## 高风险

| 风险 | 影响 | 概率 | 验证动作 | 截止点 |
|---|---|---|---|---|
| PSRAM 未在固件中启用或稳定性不足 | UI 缓存不足、崩溃或花屏 | 中 | 启动检查容量，执行全容量和DMA并发压力测试 | EVT |
| QSPI LCD、Wi-Fi、音频并发争用内存和 CPU | 花屏、爆音、丢包 | 高 | EVT 做三路满负载 24 h 压测并记录堆/任务水位 | EVT |
| 单麦无可靠 AEC | 播放时误唤醒或无法打断 | 高 | 首版固定半双工；若需打断则升级方案 B | 架构冻结 |
| ES8311 模拟链路噪声 | 唤醒率和 ASR 下降 | 中 | 独立模拟地回流、低噪声电源、录音频谱和 SNR 测试 | EVT |
| LCD 背光/功放峰值导致 5V 或 3.3V 跌落 | 重启、噪声、花屏 | 中 | 测峰值电流和电源纹波，按最坏工况留 30% 余量 | EVT |
| 云服务延迟或不可用 | 对话体验不稳定 | 中 | 流式 ASR/TTS、超时降级、断线提示和重连测试 | 联调 |
| 将屏幕VCC或IOVCC的“3V”直接接入3.3V | 屏幕损坏或QSPI逻辑异常 | 中 | 分别确认VCC/IOVCC范围；未确认前使用可调3.0V供电 | 接线前 |
| 背光A/K未使用恒流控制 | 亮度不一致、过流或损坏LED | 中 | 获取背光Vf/If并使用恒流驱动或限流方案 | 接线前 |

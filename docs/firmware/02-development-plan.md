# ESP32-C5 语音助手 - 开发计划

- 日期：2026-07-11
- 原则：先验证硬件链路，再叠加算法和云端，避免多模块同时排错。

## 阶段 1：最小系统与BSP

- 建立新的ESP-IDF工程和16MB分区表。
- 启用8MB PSRAM并打印容量、最小堆和启动原因。
- 打通USB Serial/JTAG日志、按键和LED。
- 验收：连续重启20次无异常，PSRAM容量与硬件一致。

## 阶段 2：显示

- 初始化ST77916 QSPI 360x360。
- 验证纯色、色条、旋转、背光PWM和连续刷新。
- 接入LVGL并显示固定状态界面。
- 验收：连续刷新2小时无花屏、无DMA错误、无明显内存下降。

## 阶段 3：音频

- 初始化ES8311的I2C和I2S。
- 完成录音保存/实时统计、提示音播放和音量控制。
- 做本地录音回放测试，验证通道、增益、噪声和功放使能时序。
- 验收：无持续爆音，录音波形不削顶，静音底噪可接受。

## 阶段 4：本地唤醒

- 集成ESP-SR WakeNet9s“你好小智”。
- 待命状态持续检测，触发后切换到LISTENING。
- 验收：安静环境1米距离进行50次测试，统计唤醒率和误唤醒。

## 阶段 5：网络和配网

- Wi-Fi配网、NVS保存、自动重连和时间同步。
- TLS连接和基础WebSocket/MQTT收发。
- 验收：路由器重启、信号变差和断网恢复后设备能自行回到待命。

## 阶段 6：云端语音

- 接入流式Opus上传、ASR字幕、LLM文本和流式TTS。
- 实现完整半双工状态机和超时处理。
- 验收：连续完成100轮对话，无死锁、无持续堆下降、无音频队列失控。

## 阶段 7：完善

- HTTPS OTA、资源分区、崩溃记录、看门狗和设置界面。
- 做Wi-Fi、LCD、唤醒和TTS并发压力测试。
- 验收：连续运行24小时，核心功能可恢复，最低内部堆保留明确安全余量。

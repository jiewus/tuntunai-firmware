# 后端 API 接入说明

## 1. 当前状态

旧版业务 API 已经从固件中移除。当前固件不会访问自建后端，也不会执行以下业务：

- 设备业务激活和业务访问令牌管理
- 天气查询、天气位置设置和周期刷新
- 备忘录查询、创建、修改、完成和删除
- 独立业务 MQTT 连接和设备事件同步
- 主动提醒同步、音频下载和提醒确认
- 动态 MCP 工具清单同步和远程执行

本次移除不影响小智原有的配网、OTA、ASR、大模型、TTS、WebSocket/MQTT 语音协议和
设备基础 MCP 工具。

## 2. 临时占位内容

进入表盘屏保时，`BackendService` 只向显示层写入以下本地文本：

| 区域 | 占位内容 |
|---|---|
| 天气位置 | `天气服务开发中` |
| 当前温度 | `--℃` |
| 天气描述 | `--` |
| 最低/最高温度 | `--/--` |
| 备忘录 | `备忘录服务开发中` |

占位内容不依赖网络，不创建 FreeRTOS Worker、队列或定时任务，也不会触发 HTTP 或业务
MQTT 请求。

## 3. 保留的接入点

固件保留 `main/backend/backend_service.h` 和 `backend_service.cc` 作为新版 API 的统一入口。
当前公开方法只负责兼容应用生命周期：

| 方法 | 当前行为 | 后续用途 |
|---|---|---|
| `Start()` | 输出一次占位服务启用日志 | 初始化新版后端客户端和任务 |
| `RegisterMcpTools()` | 不注册业务工具 | 注册新版自定义 API 或 MCP 工具 |
| `OnNetworkConnected()` | 空操作 | 网络可用后执行认证或同步 |
| `OnNetworkDisconnected()` | 空操作 | 停止请求并释放业务连接 |
| `OnMcpDisconnected()` | 空操作 | 取消与当前会话相关的业务调用 |
| `OnScreensaverChanged()` | 进入屏保时写入占位文本 | 按新版协议刷新天气和备忘录 |

显示层同时保留数值天气接口，并新增已格式化文本接口
`SetScreensaverWeatherText()`。后续真实天气数据可以继续使用数值接口，占位、加载和错误状态
可以使用文本接口，不需要把无效温度伪装成 `0℃`。

## 4. 新版 API 接入原则

新版 API 项目完成后，应根据最终接口文档重新实现后端模块，不得恢复已经删除的旧接口路径、
激活码、令牌结构或业务 MQTT 协议。接入时至少需要重新确认：

1. 设备认证和设备绑定协议。
2. API 根地址、请求 DTO、响应 DTO 和业务状态码。
3. 天气和备忘录的刷新时机、缓存上限与失败占位策略。
4. 自定义 MCP 工具清单和执行协议。
5. 主动提醒是否启用，以及对应的消息、TTS 和音频投递方式。

在上述协议明确之前，固件应继续保持当前无网络占位实现。
